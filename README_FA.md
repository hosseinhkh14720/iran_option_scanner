# اختیار‌یاب ایران

اسکنر خودکار اختیار معامله بورس ایران.

## کاری که انجام می‌دهد

- دریافت داده اختیارهای معامله از TSETMC
- محاسبه ارزش ذاتی Call و Put
- محاسبه ارزش مدل Black-Scholes
- برآورد نوسان تاریخی پایه
- محاسبه درصد فاصله قیمت بازار از ارزش مدل
- حذف قراردادهای بدون معامله/کم‌حجم بر اساس تنظیمات
- ساخت داشبورد HTML مناسب گوشی

## نکته مهم

APIهای TSETMC مستند رسمی عمومی و دائمی نیستند و ممکن است تغییر کنند. این پروژه endpointهای شناخته‌شده را استفاده می‌کند؛ اگر ساختار پاسخ تغییر کند، فایل `tsetmc.py` باید اصلاح شود.

همچنین GitHub Actions ممکن است بسته به مسیر شبکه/محدودیت جغرافیایی به داده TSETMC دسترسی نداشته باشد. در این صورت باید runner یا سرویس واسطی در ایران قرار گیرد.

## اجرا روی کامپیوتر

```bash
pip install -r requirements.txt
python main.py
```

بعد `docs/index.html` را باز کن.

## اجرای بدون کامپیوتر

این پروژه برای GitHub Actions + GitHub Pages آماده شده است.

1. یک Repository عمومی در GitHub بساز.
2. فایل‌های پروژه را داخل آن قرار بده.
3. در Settings > Pages، Source را روی GitHub Actions بگذار.
4. از Actions اجرای `Update Options Dashboard` را یک‌بار دستی اجرا کن.
5. آدرس Pages را با گوشی باز کن.

Workflow هر 15 دقیقه اسکن را اجرا می‌کند.

## تنظیمات

در `config.py`:

- `RISK_FREE_RATE`
- `DIVIDEND_YIELD`
- `MIN_DISCOUNT`
- `MIN_TRADES`
- `MIN_VOLUME`
- `MAX_DAYS`
- `HIST_VOL_DAYS`

را می‌توان تغییر داد.

## محدودیت ارزش‌گذاری

Black-Scholes یک مدل است و برای اختیارهای ایران باید با شرایط بازار، نقدشوندگی، فاصله قیمت خرید/فروش، اندازه قرارداد، سود نقدی و رفتار نوسان ضمنی کنترل شود. بنابراین خروجی «فرصت قطعی» نیست؛ فقط یک فیلتر محاسباتی است.
